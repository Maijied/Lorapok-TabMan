# Lorapok TabMan — Firefox Extension

Collapse all open tabs into a single, searchable dashboard. Reduce memory usage by up to 95%.

## Features

- ⚡ One-click collapse — save all open tabs and close them instantly
- 😴 Tab Snooze — auto-unload inactive tabs from memory
- ☁️ Cloud sync — sync tab groups across devices via Firebase
- 📁 Smart groups — organize with names, stars, locks, and tags
- ⌨️ Keyboard shortcuts — navigate at lightning speed

## Install (Temporary / Development)

1. Open Firefox → `about:debugging`
2. Click **This Firefox** → **Load Temporary Add-on...**
3. Select `manifest.json` from this folder
4. The TabMan icon appears in the toolbar

## Usage

1. Click the TabMan toolbar icon to collapse all open tabs into a group
2. Open the dashboard at https://maijied.github.io/Lorapok-TabMan/
3. Manage, restore, tag, and search your saved tab groups
